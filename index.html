Dispositivos e sincronização

Sincronização automática ainda não está ativa. O Android e o desktop usam cofres locais independentes. Não importe extratos financeiros reais no desktop até conectar a nuvem e validar a sincronização.

Para iniciar com a base oficial do Android, primeiro transfira uma cópia criptografada para o computador. Isso não substitui a sincronização contínua: o próximo passo será ativar o banco protegido na nuvem.

1. No Android — exportar a base oficial

No Android, abra esta mesma tela e exporte o cofre que contém os lançamentos reais. Guarde o arquivo JSON criptografado em um local protegido. Não envie o backup ao GitHub ou ao chat.

2. No desktop — preservar a base de testes

Antes de qualquer substituição, exporte o cofre atual do desktop e confira que o arquivo foi salvo.

3. No desktop — restaurar a base oficial do Android

Nenhum backup do Android validado.

Nenhuma base foi transferida.

Depois da restauração manual, os dois dispositivos ainda não estarão sincronizados automaticamente. Não faça novas alterações independentes até ativarmos a sincronização na nuvem. A senha do dispositivo de destino passará a ser a senha do Android; a biometria anterior precisará ser cadastrada novamente.

4. Sincronização criptografada — Supabase

Use uma conta da nuvem com e-mail e uma senha própria, diferente da senha do cofre. A primeira publicação deve acontecer exclusivamente no Android, depois de conferir um backup. Não configure a base fictícia do desktop como origem.

Os arquivos permanecem criptografados; nenhuma alteração é enviada sem vínculo autorizado.

Android — definir a primeira base oficial

A primeira publicação é voluntária. O aplicativo exige Android, um cofre com lançamentos e confirmação. Se já existir uma base na nuvem, esse comando será recusado para evitar sobreposição.

Computador e segundo aparelho — receber a base oficial

Após publicar no Android, acesse esta mesma conta da nuvem no computador. Faça backup do cofre local antes de receber e informe a senha do cofre do Android para abrir a cópia criptografada.

Modo protegido: a gravação automática só ocorre após o vínculo inicial. Se dois dispositivos editarem versões diferentes, o sistema interrompe o envio e mantém a cópia local para revisão. Não existe regra de sobrescrita cega baseada no relógio. Os dados financeiros são cifrados antes de chegar ao Supabase.

Importar substitui os dados deste dispositivo após confirmação. Guarde backups em um local protegido e teste sua restauração.
